Job Overview

Tech Solutions Pvt. Ltd. is looking for a motivated Frontend Developer who is interested in building modern and user-friendly web applications.

The selected candidate will work with the development team to create responsive interfaces and improve the overall user experience of web applications.

Job Description

As a Frontend Developer, you will be responsible for developing website interfaces using modern frontend technologies.

You will work closely with designers and backend developers to create functional and user-friendly web applications.

Roles and Responsibilities

  • Develop and maintain website interfaces.
  • Write clean and readable HTML, CSS and JavaScript code.
  • Build responsive web pages.
  • Work with React.js components.
  • Connect frontend applications with REST APIs.
  • Identify and fix frontend issues.
  • Work with other developers on assigned tasks.

Required Skills

  • Good understanding of HTML5.
  • Knowledge of CSS3 and responsive design.
  • Basic understanding of JavaScript.
  • Knowledge of React.js is preferred.
  • Basic understanding of Git and GitHub.
  • Problem-solving and communication skills.

Eligibility Criteria

  • BCA, B.Tech, B.Sc. or equivalent qualification.
  • Freshers can apply.
  • Basic knowledge of frontend development.
  • Interest in learning new technologies.

Salary and Benefits

  • Annual Salary: ₹3 - 5 LPA.
  • Learning and development opportunities.
  • Friendly working environment.
  • Opportunity to work on real-world projects.
  • Career growth opportunities.

About the Company

Tech Solutions Pvt. Ltd. is an IT company focused on developing web applications and digital solutions.

The company works with modern technologies and provides opportunities for developers to improve their technical skills.
